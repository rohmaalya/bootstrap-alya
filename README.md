1.	Pengertian Bootstrap [10 poin] 
Jelaskan apa itu Bootstrap dan apa kegunaannya!
Jawaban: Bootstrap adalah sebuah framework CSS front-end yang bersifat open-source dan sangat populer untuk memudahkan serta mempercepat pembuatan desain halaman web yang responsif dan ramah perangkat seluler (mobile-first). Kegunaannya antara lain menyediakan berbagai komponen antarmuka siap pakai seperti tombol, navbar, dan kartu, serta menyediakan sistem grid yang fleksibel agar tampilan web tertata rapi di berbagai ukuran layar tanpa harus menulis kode CSS dari nol.

2.	Memasang Bootstrap [10 poin] 
Ada beberapa cara untuk mengimpor atau menggunakan Bootstrap pada project. Sebutkan cara caranya!
Jawaban: Ada beberapa cara yang bisa digunakan untuk mengimpor atau memasang Bootstrap ke dalam proyek web kita. Cara pertama adalah menggunakan CDN (Content Delivery Network), yaitu dengan menyisipkan tautan link CSS dan script JS langsung ke dalam file HTML tanpa perlu mengunduh file apa pun. Cara kedua adalah mengunduh file compiled CSS and JS resmi dari situs Bootstrap lalu menyimpannya secara lokal di dalam folder proyek. Cara ketiga adalah menggunakan package manager seperti NPM atau Yarn bagi proyek web yang menggunakan build tool modern.

3.	Grid dan Breakpoint [10 poin] 
Jelaskan mengenai class grid dan kegunaan breakpoint!
Jawaban: Sistem grid pada Bootstrap adalah kerangka kerja berbasis flexbox yang memanfaatkan elemen kontainer (.container), baris (.row), dan kolom (.col-*) untuk mengatur posisi serta tata letak konten agar tersusun rapi secara horizontal dan mudah disesuaikan. Sementara itu, breakpoint adalah batasan ukuran lebar layar tertentu yang mendefinisikan kapan tata letak web harus beradaptasi (misalnya untuk layar ponsel, tablet, laptop, atau komputer desktop) sehingga tampilan situs tetap optimal di perangkat apa pun.

4.	Class Bootstrap [10 poin] 
Sebutkan minimal lima class yang disediakan oleh Bootstrap beserta kegunaannya!
Jawaban: Beberapa contoh class yang disediakan oleh Bootstrap di antaranya adalah class container atau container-fluid untuk membungkus konten agar berada di tengah dengan lebar yang responsif, class row untuk mengelompokkan kolom dalam sistem grid, serta class btn btn-success untuk mengubah tombol atau tautan menjadi tombol interaktif berwarna hijau. Selain itu, ada juga class d-flex untuk mengatur tata letak flexbox secara instan, serta class shadow atau shadow-sm untuk memberikan efek bayangan yang membuat elemen tampak memiliki kedalaman.
5.	Gambar Responsif [10 poin] 
Bagaimana cara agar foto atau gambar pada website responsif menyesuaikan ukuran layar perangkat? 
Jawaban: Agar foto atau gambar pada halaman web bisa tampil secara responsif mengikuti ukuran layar perangkat, kita cukup menambahkan class img-fluid pada elemen tag <img>. Class ini akan otomatis menerapkan aturan max-width: 100% dan height: auto, sehingga gambar tidak akan keluar dari batas wadahnya dan ukurannya bisa mengecil atau membesar secara proporsional.
